# 謝向嶸

**Python · 資料整合 · AI 應用工程**

## 我重視的工程方法

- 先定義資料契約、邊界條件與失敗行為，再實作功能。
- 以測試、對帳、log 與可重跑流程留下可驗證證據。
- 文件同時說明如何使用、如何部署、已知限制與交接方式。
- AI 協作成果必須能讀懂、能修改、能測試，也能清楚說明取捨。
